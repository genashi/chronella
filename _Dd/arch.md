## Раздел 1: Планирование времени
Страница отображает расписание на неделю в виде хронологического списка событий по дням.
### Просмотр:

- Список событий на день/неделю
- У каждого события: название, время начала/конца, тип, местоположение, преподаватель
- Кнопка "отметить как посещённое" на каждом событии
- Аналитика загруженности (по формулам)

### Редактирование:

- Пользователь входит в режим редактирования для дня или недели
- Может добавить кастомное событие с произвольными атрибутами
- Может вытянуть расписание из ЭИОС для выбранного периода
- При вытягивании система сравнивает новые данные из ЭИОС с тем что уже есть:

- Новые события — добавляются
- Изменившиеся (время, аудитория, препод) — студент видит diff и решает: принять изменение или оставить своё
- Удалённые из ЭИОС — помечаются, студент решает что с ними делать


Отредактированные вручную события помечаются флагом, чтобы система знала не перезаписывать их автоматически

### Атрибуты пар из ЭИОС:

- Тип занятия (редактируемый)
- Аудитория/корпус → поле "местоположение" при экспорте в Google Calendar
- Имя преподавателя → поле "описание" при экспорте

### Экспорт в Google Calendar:

У Хронеллы свой отдельный календарь внутри Google Calendar пользователя — чужие календари не трогаем
Для каждого события хранится google_event_id — при экспорте делаем upsert (создать если нет, обновить если есть)
Удалённые из Хронеллы события удаляются и в Google Calendar точечно, без очистки всей даты


## Раздел 2: Успеваемость
Работаем с текущим семестром (расширение на другие — если останется время).
### Просмотр:

Список дисциплин
- Каждая дисциплина раскрывается в список контрольных точек
- Для каждой точки: название, тип, дедлайн, статус, набранные баллы
- Если у точки есть возможность прикрепить файл в ЭИОС — это обозначено
- Аналитика по дисциплине (баллы, прогноз итоговой оценки)

### Редактирование:

- Дедлайн из ЭИОС можно скорректировать вручную (исходный сохраняется в eios_raw)
- Студент вручную отмечает точку как сданную вовремя / с опозданием — это влияет на метрику "успешности" внутри - дисциплины
- Если у точки нет дедлайна — тип по умолчанию "контрольная", дедлайн можно добавить позже
- Тип работы выбирается вручную; для типов без дедлайна (контрольная, тест на паре) статус "сдано вовремя" не запрашивается

### Баллы:

- 70 баллов за семестр + 30 за зачёт/экзамен
- На основе текущих баллов считается прогноз и аналитика

### Экспорт дедлайнов в Google Calendar:

Дедлайн контрольной точки можно экспортировать как событие на весь день
Аналогично через upsert по google_event_id

## Предполагаемая база данных
```
users
  id, email, password_hash, created_at
  eios_token, eios_token_expires_at
  google_access_token, google_refresh_token, google_token_expires_at
  google_calendar_id  ← id календаря хронеллы в Google

events  ← расписание (пары + кастомные)
  id, user_id
  title, type (lecture/practice/lab/custom/...)
  start_at, end_at
  location, description
  teacher (из ЭИОС)
  is_visited (bool)
  is_modified (bool)  ← студент редактировал?
  eios_raw (JSON)     ← оригинал из ЭИОС, null если кастомное
  google_event_id     ← для upsert, null если не экспортировали

disciplines
  id, user_id
  name, semester
  eios_id

control_points
  id, discipline_id
  title, type (homework/test/exam/coursework/...)
  deadline (nullable)
  has_file_upload (bool)
  score (nullable)
  max_score
  is_submitted (bool)
  is_late (bool)
  eios_raw (JSON)
  google_event_id  ← если экспортируем дедлайн в календарь
```
